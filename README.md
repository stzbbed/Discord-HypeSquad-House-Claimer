# Discord HypeSquad House Selector

A script allowing Discord users to claim the Hypesquad House badges that are now unavailable to obtain through the Hypesquad House Quiz.

---

## Features

- Choose between the three HypeSquad houses:
  - **Bravery**
  - **Brilliance**
  - **Balance**
- Hidden token input using `getpass`
- Lightweight and easy to run
- Communicates Discord's API
- Basic error handling for failed requests

---

## Requirements

- Python 3.8+
- Requests library

---

## Installation

### 1. Clone the repository

```
git clone https://github.com/stzbbed/Discord-HypeSquad-House-Selector.git
```

2. Navigate to the project directory

```
cd Discord-HypeSquad-House-Selector
```

3. Install dependencies

```
pip install requests
```

## Usage

Run the script:


```
python main.py
```

You will see the following menu:

```
Discord HypeSquad House Selector
1. Bravery
2. Brilliance
3. Balance

Choose your house (1/2/3):
```

Select your preferred house by entering its corresponding number.
Then, paste your authorization token.

*Your authorization token is not displayed on the screen. You just need to paste it and press enter. 
Never share, publish, or commit your authorization token unless you know what you are doing. Anyone that has your token can gain full access to your discord account. If your token got leaked or stolen, immediately change your account password.*
